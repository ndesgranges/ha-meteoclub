## Installation

Make sure you got access to a self-hosted
[MeteoClub](https://github.com/ndesgranges/meteoclub) instance.
Then you can follow of the two following methods.

### HACS (Recommended)

[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=ndesgranges&repository=ha-meteoclub&category=integration)

OR

1. Install HACS if you don't have it already
2. Open HACS in Home Assistant
3. On the top right side, click the three dot and click `Custom repositories`
4. Where asked for a URL, paste the link of this repository:
https://github.com/ndesgranges/ha-meteoclub
5. Where asked for a type, select `integration`
6. Click the download button. ⬇️

### Manual

Copy the `custom_components/meteoclub/` folder into your HA `config/custom_components/` directory.
